# Carpeta de Galería
Sube aquí tus fotos para la invitación. 
Nómbralas como `foto1.jpg`, `foto2.jpg`, `foto3.jpg`, `foto4.jpg` para que aparezcan automáticamente en la sección de galería.
También puedes subir una foto llamada `lugar.jpg` en la carpeta superior `public/images/` para la foto del evento.
